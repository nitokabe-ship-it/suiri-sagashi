# 水利さがし 管理者向けメモ

## ファイルの役割(直す場所の目安)
| ファイル | 役割 | 直すとき |
|---|---|---|
| `index.html` | 利用者の画面の骨組み(文字・ボタンの配置) | 文言やボタンを変える |
| `style.css` | 見た目(色・大きさ) | 文字の大きさ、色を変える。先頭の `:root` が目印 |
| `config.js` | **数値と設定**(地図の中心、範囲のボタン、ホース1本の長さ…) | 設定を変えるだけなら、ここだけ |
| `data.js` | 共通部品(保存、水利データ、住所検索、CSV取り込み、現場の状態) | データの扱いを変える |
| `app.js` | 画面の動き(A〜Gの見出しで区切ってあります) | 機能を足す・直す |
| `admin.html` | 管理画面(CSV取り込み) | 取り込みの方法を変える |
| `water.csv` | 水利データ(種別,名称,緯度,経度)。全員が自動で読む | **年1回、データ更新時に差し替え** |
| `quiz.html` | 地水利クイズ(別の画面) | クイズを直す |
| `sw.js` | 通信が悪いときの備え | `const C='sr-v11'` を上げると全員が新しい版になる |
| `vendor/` | 地図の部品(Leaflet)。触らない | |
| `_old/` | 以前の版(参考) | 不要なら削除 |

## 画面に出る文言の直し場所
- 水利データの日付(一覧の下に出る): `config.js` の `data.asOf`。**データを差し替えたら必ず直す**(いまは仮の「令和7年4月1日版」)
- 出典・ライセンスの文章: `config.js` の `CONFIG.credits`(画面では「使い方」→「出典・ライセンス」を開いたときだけ表示)
- 版の日付: `config.js` の `version`

## 年1回のデータ更新(東京消防庁)
1. 東京都オープンデータカタログから、消火栓・防火水槽等のCSVを入手する。
2. `種別,名称,緯度,経度` の形にそろえ、`water.csv` として置き換える(文字コードはUTF-8)。
3. `config.js` の `version` を日付に更新する。`sw.js` の `sr-v12` の数字を1つ上げる。
4. 出典表示(CC BY 4.0)は、画面の「使い方」の最後に入っています。

## 公開
GitHub Pages に、このフォルダの中身を**そのまま**置きます(`vendor/` フォルダも一緒に)。

## 動作確認チェックリスト(更新のたびに)
- [ ] 住所を入れて「さがす」→ 火点と水利が出る
- [ ] 水利を押す → 状態ボタンと、ホースの長さ・本数が出る
- [ ] 「使用可」を押す → 地図の色と記号が変わる
- [ ] 「経路を描く」→ タップで経路ができ、長さが変わる
- [ ] 「＋マーカー」→ 消防車・積載車・警備地点・通行止めを置ける/削除できる
- [ ] 「共有」→ リンクを別の端末で開くと同じ状態になる
- [ ] 文字の大きさを変えても、ボタンが崩れない
- [ ] スマホ(iPhone/Android)とPCの両方で確認

## 注意(運用)
- 現場の状態は**各端末に保存**され、他の端末に自動では届きません。共有は「共有リンク」で送ります。
- 徒歩ルートは OSRM の公開サーバー(非営利・1秒1回まで・予告なく停止の可能性)を使っています。取得できないときは「直線×1.3」の目安に自動で切り替わり、**手で描いた経路が常に使えます**。
